# Changelog

All notable changes to the **seo-pulse** plugin will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/),
and this project adheres to [Semantic Versioning](https://semver.org/).

## [1.6.0] - 2026-10-26

### Added
- Flag sustained traffic declines across comparable weekly windows.

## [1.5.0] - 2026-10-26

### Added
- Recommend specific internal links with source ownership and measurement holds.

## [1.4.0] - 2026-10-26

### Added
- Distinguish possible page conflicts from normal URL overlap.

## [1.3.0] - 2026-10-26

### Added
- Show two- and four-week outcomes against fixed baselines with data limits.

## [1.2.0] - 2026-10-26

### Added
- Check page intent before recommending an SEO change.

## [1.1.0] - 2026-10-25

### Added
- Support first-run assessments and product portfolios with shared measurement holds and separate source repositories.

### Fixed
- Accept search results with document anchors and keep every section on hold while its page is measured.

## [1.0.0] - 2026-10-23

### Added
- Add configurable SEO cycles with measurement checks and weekly reports that file signal issues without editing sites.
